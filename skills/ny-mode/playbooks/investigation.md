# Investigation

Read-only for product code. The deliverable is a cited answer. Updating the feature map is the one allowed edit.

1. Restate the question in one sentence.
2. Load the repo skill and the feature map entry for the area.
3. Open the files the map names. Search only for what the map lacks.
4. Answer with `path::symbol` citations and the proof level of each claim. Run a small script when a claim is cheap to execute.
5. Add any location you had to search for to the feature map.

**Reply:** the answer first, then the evidence, then what you could not confirm.
